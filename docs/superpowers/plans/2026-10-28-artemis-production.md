# ARTEMIS Production Experience Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

> Historical plan: the later owner-selected interface reference supersedes its non-photographic Home composition. See `2026-10-28-reference-fidelity.md`; engine safeguards remain unchanged.

**Goal:** Complete the approved ARTEMIS product experience over the existing truthful Sabra engine.

**Architecture:** Retain FastAPI server-rendered pages and stable JSON routes. Add one focused editorial theme module, locally served licensed fonts/assets, and additive data-backed intelligence fields. The engine remains the authority for readiness, approval and submission state.

**Tech Stack:** Python, FastAPI, SQLAlchemy, vanilla browser JavaScript, Playwright, pytest, Ruff.

**Spec:** `BRAND.md`, `docs/brand/ARTEMIS_APPROVED_DIRECTION.md`, `SABRA_JOB_ENGINE_V1_BUILD.md`.

## Global Constraints

- ARTEMIS is the sole customer identity. Keep internal `sabra` identifiers.
- Candidate truth, sensitive answer verification, content-hash approval, CAPTCHA human handoff, dry-run and confirmation gates remain intact.
- No external application submissions in this work.
- No invented activity, percentages, company facts or pilot results.
- No sidebar, photography, glass dashboard or architecture rewrite.
- Use the exact canonical evergreen, forest, sage, stone, sand, porcelain and graphite palette; licensed local serif and sans.

## Review Focus

- Empty private database: show setup and honest absence, never seeded production achievements.
- Incomplete/unverified packages: surface unresolved questions and keep approval disabled.
- Questions containing both why and opportunity: explain actual fit rather than route to generic listings.
- Run changes: state the actual recorded run baseline, without implying a calendar comparison.
- Narrow screens, long titles/URLs/documents: remain navigable without page overflow.
