Date: 2026-10-28. Baseline: `04a1021be63824099c88c4792cbc82c135bf1cd7` (merged PR #14). This release preserves the FastAPI server-rendered application and Sabra engine; `apps/web` remains an unused scaffold.

## Delivered

- Shared architectural editorial shell: canonical porcelain/evergreen palette, local Cormorant Garamond display type and Manrope UI type, horizontal navigation, keyboard focus/skip link, reduced-motion support and responsive forms/tables. The OFL licenses are bundled.
- Morning Brief: actual current shortlist, one prioritized next action, stored run counts and timestamps scoped to the active candidate/search. Failed attempts and absent runs are stated. Research counts describe roles, not distinct employers. There is no claimed calendar-day comparison.
- Opportunities: original posting provenance, explained fit/strengths/gaps, source-backed research separated from inference, application readiness and history.
- Application Studio: readable escape-first document previews, section navigation, proposed answers/truth levels, unresolved questions, warnings, exact approval hash and unchanged approval controls.
- Pursuit Pipeline: honest lifecycle stages, submission status, stage navigation, recorded outcomes and durable history.
- Career Plan: stated targets/constraints, recorded assessment evidence, inferred gaps and suggested development actions.
- Ask Artemis: deterministic answers from actual stored data, specific recommendation intent before broad match intent, recorded developments/run changes and explicit limits.
- Original production A kit: master, horizontal/stacked/symbol, light/dark/mono, favicon, app icons, social SVG/PNG and 16 px exports. Distributed vector lettering is outlined; standalone files need no installed font. Asset regeneration was run twice with identical SHA256 inventories.
- Wheel packaging includes brand assets/fonts and uses a packaged-path fallback outside a source checkout.
