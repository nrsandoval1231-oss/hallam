# Hallam

Hallam is the repository for Sabra Job Engine V1, an outcome-driven job-search operator with human control at the external application submission boundary.

The canonical build contract is [`SABRA_JOB_ENGINE_V1_BUILD.md`](SABRA_JOB_ENGINE_V1_BUILD.md). Read it before coding.

## Repository layout

- `apps/` — web and API applications
- `packages/` — domain, providers, scoring, documents, and automation packages
- `workers/` — discovery, research, and application workers
- `migrations/` — database migrations
- `tests/` — automated tests
- `docs/` — architecture, decisions, and operations documentation
- `scripts/` — development and operational scripts
